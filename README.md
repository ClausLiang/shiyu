# 拾语 · 英语学习小工具

一个先从英语四级单词开始的网页版学习工具。第一版包括 2607 个单词、131 个章节、卡片拼写和浏览器本地进度；语句、文章、账号和云端同步留待后续实现。

在线使用：[拾语](https://liangyonggang.com/shiyu/)。已通过 GitHub Pages 发布，默认地址 https://clausliang.github.io/shiyu/ 会重定向到该地址。

## 启动

需要 Node.js 22 或更高版本，无需安装第三方依赖。

```sh
npm run dev
```

打开 http://127.0.0.1:5173 。本地服务只监听本机地址。

```sh
npm test          # 核心逻辑测试
npm run build    # 生成静态文件到 dist/
npm run preview  # 在同一端口预览 dist/，先关闭 dev 服务
```

服务没有热更新；修改代码后刷新浏览器。`PORT` 环境变量可指定端口。构建产物支持部署到静态托管根路径或子目录。

## 如何学习

1. 选择章节，一页显示 20 个单词，最后一章显示 7 个。
2. 点击卡片，单词变模糊，保留中文提示。输入后按 Enter 或箭头按钮检查。
3. 拼对后显示单词并记为已练习；拼错时可继续尝试。按 Esc 或“查看单词”查看答案，不计完成。
4. “开始 / 继续本章练习”定位本章第一个未完成词；已经完成整章时可再次练习。
5. 从侧栏“进度与备份”或页面右上角保存状态进入备份窗口。

一次拼对只代表已练习，不代表已经长期掌握。拼写不区分大小写、忽略首尾空白；保留词库中的英美拼写原样，例如 `analyse` 需按卡片上的形式拼写。

## 本地记录

- 使用版本化 localStorage 数据，保存当前章节、每词尝试次数、正确次数、完成状态和最近练习时间。
- 进度按浏览器及网站地址隔离；请固定使用同一个地址。`localhost` 与 `127.0.0.1`、不同端口、不同浏览器的记录不互通。
- 清除浏览器数据会清除进度。换设备前可导出 JSON 备份，在新设备导入。
- 导入前校验结构、版本、词库、词条与计数。与当前进度合并，保留当前章节；完成状态取并集，次数取较大值，重复导入不会重复计数。
- 备份不是跨设备实时同步；离线分支的尝试次数不会相加。后续账号版本需引入独立练习事件 ID。
- 本地数据损坏时不会自动覆盖原始数据；当前页进入临时学习模式，提示导出备份。存储失败时不会假装保存成功。
- 首次读取词库需通过本地 HTTP 服务，不能直接双击 HTML 文件。没有 Service Worker，不承诺关闭服务后仍可重新打开。
