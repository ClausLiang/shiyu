# 拾语 · 英语学习工具项目计划

更新：2026-10-08

## 目标与范围

逐步提供单词、语句、文章三个学习模块。当前提供四级单词学习和语句阅读、听音，文章仍为后续规划。先在浏览器本地使用，账号与远端同步放到后续阶段。

## 第一阶段产品约定

- 使用 Qwerty Learner 公开 CET-4 词库，保持原顺序。已核验 2607 个不重复词条。
- 每章 20 个词，共 131 章，第 131 章 7 个词。一个页面展示整章，支持上一章、下一章和章节目录跳转。
- 每个单词一张卡片，展示单词、音标、中文释义。点击卡片进入拼写，单词模糊、音标隐藏，中文保留作为提示，并自动发音一次；通过“开始 / 继续本章练习”进入拼写也适用。输入、提交检查和查看答案不会额外触发发音。
- 每张卡片右上角可点击发音，拼写时也能听；浏览器语音默认优先美式，没有美式时使用其他英语语音，不改变拼写输入或练习进度。连续点击切换播放，切章、隐藏页面或离开页面时停止；不支持、缺少英语语音或播放失败时明确提示。
- 输入后按 Enter 或点击检查。去掉首尾空白、不区分大小写，其余必须一致；不在输入过程中提前判错。
- 正确后恢复单词并记为“已练习”；错误保留输入、明确提示，允许重试；Esc 或“查看单词”退出，不增加完成数。
- 本章全部单词已练习，且最近一次拼对的是本章末词时，按 Tab 弹出庆祝窗并播放完成旋律；支持直接 Tab 提交，以及 Enter / 检查按钮提交后再 Tab。已完成章节复习末词也可庆祝；关闭弹窗后不重复触发，可进入下一章、从首词复习或留在当前章，末章可返回第一章。
- 章节进度入口在桌面固定顶栏常显、手机右下角常显，点击打开章节目录；自动滚动须避开顶栏，确保输入框可见。
- 一次拼对仅表示已练习，不等于长期掌握。重复练习不重复累计单词数，保留尝试数、正确数、最近练习时间。
- 保存当前章节和各单词记录；刷新恢复。支持 JSON 备份导出、校验后合并导入。存储不可用时明确提示。
- 桌面与手机均可使用，支持键盘操作与可见焦点。

## 语句学习产品约定

- 数据保存在本地 `public/data/sentences.json`，由用户逐条提供英文原句和中文翻译；按收录顺序追加，不自行生成语料。
- 展示英文原句和中文翻译，发音按钮紧跟英文原句，复用现有浏览器发音功能。
- 每页 10 句，支持上一页和下一页，尾页展示剩余句子，首尾禁用越界按钮。
- 连续点击发音时切换播放，翻页、切换学习模块、隐藏或离开页面时停止；长句在开始播放后按词数延长超时保护，避免固定 15 秒中断。
- 当前只提供阅读和听音，不引入拼写判定、完成统计或语句进度存储；同一页面内切换模块保留语句页码，刷新回到默认单词页面。
- 空数据、加载失败和发音失败时明确提示；加载失败允许重试。桌面和手机均可使用。

## 全站主题

- 提供浅色和深色两种主题，默认保持浅色；顶栏按钮在桌面和手机端均可使用，按钮状态表示深色模式是否开启。
- 主题覆盖单词、语句、输入框、进度、提示和弹窗；切换只更新配色，不重绘卡片、不清空输入、不修改学习进度。
- 偏好使用独立的 `shiyu:theme:v1` 保存到当前浏览器，在首屏渲染前恢复，刷新后保持选择；同源标签页同步偏好。不跟随系统自动切换。
- 无法读取或偏好无效时使用浅色；保存失败仍在当前页应用主题并提示，不宣称已保存。

## 技术方案

- 原生 HTML / CSS / JavaScript ES Modules；Node.js 22+ 提供本地静态服务、构建与测试，零第三方运行依赖。
- 数据随项目保存，应用不依赖词库网站的实时可用性；词库来源与版本摘要独立记录。
- `src/learning.js`：章节、拼写和进度校验等纯逻辑。
- `src/sentences.js`：语句数据校验与分页逻辑。
- `src/storage.js`：本地存储适配层；后续可替换为远端同步实现。
- `src/main.js`：卡片、导航、统计与备份交互。
- `src/theme.js`：轻量普通脚本，在样式和内容加载前恢复主题，并处理切换、偏好保存与同源标签页同步。
- `src/pronunciation.js`：使用 Web Speech API，无后端与 API 密钥，优先本地美式音色；音色由浏览器和设备提供，部分语音需要联网。
- localStorage 使用版本化数据结构，以单词名称为稳定标识，不绑定数组下标。
- `npm run build` 输出静态目录 `dist`，未来可选择静态托管。

## 实施里程碑

1. 需求与数据：计划、交互规则、词库获取、来源记录。
2. 单词学习 MVP：响应式布局、分章、卡片拼写、状态提示、进度统计。
3. 本地持久化：章节恢复、进度备份、异常处理。
4. 验证与交付：核心逻辑测试、浏览器交互与移动端检查、启动说明。
5. 后续迭代：结合实际使用讨论复习机制、错词筛选、发音体验改进、每日目标。
6. 账号与同步：评估免费服务（配额与休眠策略以实施时为准），确定身份验证、冲突合并、备份迁移后再实现。
7. 语句学习：先实现用户提供语句的本地收录、中英展示、浏览器发音与每页 10 句，再根据实际使用讨论练习机制。
8. 文章学习：先讨论内容来源、学习交互及拆句方式，再进入开发。

## 后续需要讨论的方向

- 已练习到掌握的标准：拼对一次、跨天复习，还是间隔重复。
- 卡片拼写时是否保留中文提示（第一版保留）。
- 根据浏览器语音体验，评估是否需要英美切换或授权音频。
- 免费远端服务的访问稳定性、区域、账号方式与迁移成本。
- 对外发布前核对词库再分发许可；当前仅取得公开数据，不能把公开可访问当作已确认授权。

## 验收标准

- 2607 个词完整覆盖，无重复或遗漏；最后一章 7 个，首尾不能越界。
- 点击卡片模糊单词并聚焦输入；正确恢复、错误可重试，查看答案不计完成。
- 切章与刷新不丢已保存记录；复练不虚增进度。
- 本地数据损坏、存储失败、词库加载失败时给出可理解的提示。
- 可备份和合并恢复，不用导入覆盖已有正确记录。
- 语句原文与译文准确展示，每页最多 10 句，英文后的按钮朗读完整原句；翻页和切换模块停止播放，不影响单词进度。
- 项目进度持续写入 `docs/PROGRESS.md`。
