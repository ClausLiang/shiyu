## 2026-09-22 · 修复进度胶囊随页面滚动消失（顶栏 sticky）

- 用户反馈：桌面端放进顶栏后，进度胶囊会跟着页面一起滚走，一滚动就看不到进度。修复：`.topbar` 改为 `position:sticky;top:0;z-index:3`，背景提高到 85% 白，滚动时顶栏连同进度胶囊、保存状态固定在视口顶部。
- 连带发现并修复手机端问题：顶栏上的 `backdrop-filter` 会让顶栏成为 `position:fixed` 后代的包含块，手机档胶囊的 `fixed;right:14px;bottom:14px` 变成相对顶栏定位，贴不到屏幕右下角。把毛玻璃移到 `.topbar::before` 伪元素（伪元素不是祖先，不影响 fixed 定位），模糊效果保留，手机档恢复贴右下角。
- 测试断言修正：滚动中卡片从顶栏下方经过是 sticky 头部的正常行为，遮挡判定改为只统计「位于顶栏下方区域（top ≥ 顶栏底边）却被胶囊矩形盖住」的元素，并新增「滚动中胶囊始终收在顶栏内」断言。
- 验证：Chrome 无头实测 24 项全通过——滚动 900px 后顶栏（top=0）与胶囊（top=14）仍固定可见、真实遮挡元素为空、滚动中胶囊始终收在顶栏内、手机档（390 宽）胶囊 right/bottom 精确 14px、无横向滚动；截图核对桌面滚动中与手机底部两档。`npm run build` 重新生成 `dist/`。

## 2026-09-23 · 庆祝弹窗严格区分首次学习与复习两种场景

- 按用户要求细化规则：**首次学习**时本章必须全部单词都完成，才在末词拼对加 Tab 时弹窗，中途漏词则不弹；**复习**时以「本轮开始前本章已全部学完」为条件，拼对末词加 Tab 即弹窗。
- 原判据无法区分这两种场景：整章一旦补齐，`completedCount` 就等于总数，「本来满的（复习）」与「刚才补满的（首次）」无法区分。新增模块级 `chapterWasComplete` 快照，在 `activate()` 中「从查看态进入」（即新一轮开始）时记录本章是否已完成；切章与导入进度时重置。
- `advanceToNext()` 的庆祝条件：先要求拼对的确实是本章最后一个单词，再取「快照为真（复习）或本次补齐全部缺口（首次学习）」。
- 边界：复习场景中途用 Esc / 点击跳词不影响庆祝（条件是「之前已学完」，而非「逐个走过」）；未学完的章节单独练习末词不弹窗；每轮复习走完末词都可再次获得奖励。
- 验证：`node --check`、测试（29 项）、`npm run build` 通过；新增实测 17 项全通过——首次学习漏词 19/20 时末词不弹窗且提示不变、补齐后走完整轮弹窗、复习场景弹窗、复习中途跳词仍在末词弹窗、未完章单点末词不弹窗；原有三套实测（13 + 19 + 10 项）全部通过，合计 59 项。

## 2026-09-23 · 复习时走完本章末词也给予庆祝

- 用户反馈：上一版只在「首次补上最后一个缺口」时庆祝，导致复习时永远不再弹窗。确认采用方案 B：**拼对本章最后一个单词即庆祝**，不论此前是否已完成整章。
- `advanceToNext()` 的庆祝条件改为两者取并：本次拼对刚好补上最后一个缺口（首次学完整章），或本次拼对的就是本章最后一个单词（复习走完整轮）。前者覆盖中途跳过部分词、最后补齐的情形，后者覆盖复习与单独练习末词的情形。
- 效果：复习逐词推进时不会被打扰，只有走到末词（或直接练末词）才弹窗并播放庆祝旋律；每完成一轮都可以再次获得，奖励可重复。未走到的位置不受影响。

## 2026-09-23 · 修复复习已学完章节时每次按 Tab 都弹庆祝窗

- 用户反馈：复习本章单词时，每按一次 Tab 都会触发庆祝弹窗，无法逐词复习。原因是原判定用 `completedCount(...) === current.length` 这个**持久状态**作条件，整章学完后该条件恒成立，于是每次 Tab 都弹窗。
- 改为判定本次动作的变化量：拼写态先记录拼对前后的完成数，只有这次拼对才补上最后一个缺口（`before < 总数 && after === 总数`）才庆祝；复习时每个词本就已完成，条件不成立，按 Tab 只逐词切换。查看态按 Tab 也不再有弹窗分支。
- 顺带修复复习入口：`celebrateChapter()` 清空学习游标，避免首轮学完时游标停在末词、之后回访该章按 Tab 因越界卡住；现在查看态按 Tab 会从本章第一个词开始复习。
- 验证：`node --check`、测试（29 项）、`npm run build` 通过；Chrome 无头实测 11 项全通过——首次学完整章仍弹窗、复习态查看按 Tab 从第 1 词开始且不弹窗、连按 Tab 复习完整章 0 次弹窗、复习到末尾停在原地提示、切到新章节首次学完仍弹窗（回归）、再次回访已学完章节仍不弹窗；原庆祝弹窗测试更新期望后 19 项全通过。
